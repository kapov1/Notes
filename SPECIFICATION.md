# Требования:

## Обязательные:

### Создание заметки 
  У пользователя должна быть возможность создать заметку с содержанием, идентификатором пользоваетля, названием и тегами. Дата должна указываются автоматически. На заметке может быть несколько тегов.
  
### Поиск заметок
  Поиск должен осуществялтся по: названию заметки, уникальному идентификатору пользователя или заметки.
  
### Сортировка при поиске заметок
  При поиске должна присутстовать сортировка. Параметрами сортировки могут быть дата, длина заметки или количество тегов. Для каждого параметра можно выбрать правило сортировки: по убыванию или по возрастанию.

### Изменение данных заметки 
  Данные заметки можно изменить по ее уникальному идентификатору. Можно изменить только содержание, теги и название заметки.

### Удаление заметок
  Заметку можно удалить по ее уникальному идентификатору. После удаления заметку восстановить нельзя.

### Пагинация при получении заметок
  Для получения всех заметок должна использоватся пагинация с указанием страницы и количества заметок на одной странице.

### Создание пользователя
  Можно создать пользователя от чьего имени будут создаватся заметки. При создании указывается имя.

### Изменение данных пользователя
  Можно изменить данные пользователя. Можно изменить только имя.

### Поиск пользователей
  пользователя можно найти по его ID или по имени. При поиске должна быть возможность сортировки по имени. 

### Пагинация при получении пользователей
  Для получения всех пользователей должна использоватся пагинация с указанием страницы и количества заметок на одной странице.

### Удаления пользователя
  При удалении пользователя удаляются все его заметки.
