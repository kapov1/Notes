# Требования:

## Обязательные:

### 1. Создание 
  У пользователя должна быть возможность создать заметку с содержанием, авторством, названием и тегами. Дата должна указываются автоматически. На заметке может быть несколько тегов.
  
### 2. Поиск
  Поиск должен осуществялтся по: названию заметки или уникальному идентификатору.
  
### 3. Сортировка 
  При поиске должна присутстовать сортировка. Параметрами сортировки могут быть дата, длина заметки или количество тегов. Для каждого параметра можно выбрать правило сортировки: по убыванию или по возрастанию.

### 4. Изменение данных
  Данные заметки можно изменить по ее уникальному идентификатору. Можно изменить только содержание, теги и название заметки.

### 5. Удаление заметок
  Заметку можно удалить по ее уникальному идентификатору. После удаления заметку восстановить нельзя.

### 6. Пагинация
  Для получения всех заметок должна использоватся пагинация с указанием страницы и количества заметок на одной странице
